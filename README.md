# התקציב שלי

אתר פשוט לתקציב חודשי. אין חשבונות משתמשים ואין מסך התחברות.

## פריסה

האתר מוכן לפריסה ב־Netlify. הקבצים הסטטיים נפרסים ללא שלב בנייה, ו־Netlify Function שומרת את התקציב ב־Netlify Blobs. אחרי שהפונקציה זמינה, האתר מסנכרן נתונים בין מכשירים.

## גישה לנתונים

אין אימות או מזהה משתמש: האתר והנתונים יהיו פתוחים לכל מי שיגיע לכתובת האתר, שיוכל לראות ולשנות את התקציב. נתונים מהגרסה המקומית לא מועלים אוטומטית עד שיש חיבור פעיל לאתר Netlify.
