# התקציב שלי

אתר תקציב בעברית, במצב כהה קבוע וללא משתמשים או מסך התחברות.

## מודל התקציב

- מחזור התקציב מתחיל ביום המשכורת (ברירת המחדל היא 10) ומסתיים יום לפני המשכורת הבאה.
- לכל מחזור יש יעדים לקטגוריות של הוצאות משתנות.
- הוצאות קבועות והחזרים חודשיים מופיעים כהתחייבויות; סימון תשלום רושם את התנועה.
- קנייה באשראי נספרת בתקציב בתאריך הקנייה. יום סגירת החשבון ויום החיוב ניתנים לשינוי; ברירת המחדל לשניהם היא 15, ויש להתאים את יום הסגירה לדף החשבון האמיתי.
- משיכת מזומן היא העברה בין הבנק לארנק, וקניית מזומן היא ההוצאה.
- היתרות הן הערכה לפי יתרות פתיחה ותנועות שהוזנו, לא חיבור אוטומטי לבנק.
- רישום יעד לעודף הוא תכנון בלבד; הוא לא מעביר כסף ולא משלם חוב בפועל.

## פריסה ושמירת מידע

האתר נפרס ב-Netlify ללא שלב בנייה. Netlify Function שומרת את התקציב המשותף ב-Netlify Blobs ומאפשרת סנכרון בין מכשירים.

אין אימות או מזהה משתמש: האתר והנתונים פתוחים לכל מי שיגיע לכתובת האתר, וניתן לראות ולשנות אותם. אין להכניס מידע שאינך מוכן שיהיה ציבורי.

## חיבור בוט טלגרם

כדי להפעיל את הבוט, צריך ליצור בוט דרך BotFather ולהגדיר ב-Netlify את משתני הסביבה הבאים. אין לשמור את הערכים בקוד, ב-GitHub או בדפדפן:

- `TELEGRAM_BOT_TOKEN` — המפתח שקיבלת מ-BotFather.
- `TELEGRAM_WEBHOOK_SECRET` — מחרוזת אקראית שתישלח בכותרת לכל webhook.
- `TELEGRAM_PAIRING_CODE` — קוד חיבור אישי; ישמש גם להפעלת ה-webhook וגם לקישור הצ'אט הפרטי.

לאחר שמירת המשתנים ופריסה מחדש, פותחים באתר את **טלגרם**, מזינים את קוד החיבור ולוחצים **הפעלת הבוט**. אחר כך פותחים צ'אט פרטי עם הבוט ושולחים `/pair` ואת אותו קוד. הבוט רושם סכום, תיאור, קטגוריה ואמצעי תשלום; אם חסרים סכום או אמצעי תשלום, הוא ישאל לפני הרישום. כל הודעת הוצאה שנרשמה מקבלת כפתור ביטול.
